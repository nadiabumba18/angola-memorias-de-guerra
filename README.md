# Angola — Memórias de Guerra

Projeto único, preparado para web responsiva e empacotamento multiplataforma (Android, iPhone/iPad e PC).

## Incluído nesta versão
- Campanha de 20 níveis com progressão e repetição até passar.
- Capa e interface adaptável para telemóvel, tablet e computador.
- Abertura com `abertura.opus`, sequência visual e trilha instrumental original `musica_abertura_original.wav`.
- Final com `final.opus` e sequência visual.
- Imagens de missão para os 20 níveis.
- Multiplayer WebSocket, contas, amigos, progresso e chat.
- PWA (manifest + service worker).

## Publicação
A versão web pode ser publicada no Render. Para Android/iOS/iPadOS é necessário empacotar esta mesma aplicação com uma ferramenta nativa (por exemplo, Capacitor) e fazer builds/testes em ambientes apropriados. A publicação nas lojas exige contas de desenvolvedor e aprovação das respetivas lojas.

## Nota sobre música
A trilha incluída é original e não é a gravação comercial de "Angola" de Matias Damásio nem de "Jeito Alegre de Chorar" de Paulo Flores.
